SPACING
The report table uses these column widths: Staff 15%, Date 12%, Clock In 12%, Clock Out 12%, Duration 12%, Overtime 12%, Idle Time 12%, Notes 13%. This reduces the Staff-to-Date gap and gives the middle time columns equal space while keeping Notes at the far right. Cell padding is compact and consistent.

WHY THE PDF CAN STILL SHOW 404
A 404 means Next.js is not registering the API handler. The correct physical path is exactly:
  <project-root>/src/app/api/clock-tracker/report/route.ts
It must NOT be placed at any of these paths:
  src/app/(app)/clock-tracker/route.ts
  src/app/clock-tracker/api/clock-tracker/report/route.ts
  src/app/(app)/api/clock-tracker/report/route.ts

INSTALL/TEST

4. Confirm src/app/(app)/clock-tracker/ contains page.tsx, clock-button.tsx, actions.ts and live-work-time.tsx, but no route.ts.
5. Stop Next.js with Ctrl+C. Restart with npm run dev. If necessary, stop the server, delete the project's .next directory, and restart.
6. While signed in, open http://localhost:3000/api/clock-tracker/report. A successful request downloads JAAD-Clock-Tracker-Report.pdf. A 401 means sign in; a 500 means inspect the terminal for database/schema errors. A 404 means the route file is still not in the active app root or the server has not restarted.
