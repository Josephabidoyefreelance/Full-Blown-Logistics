JAAD-ISOLATION-STAGING: authenticated, read-only security test.
1. Copy JAAD-STAGING-AUTH-READ-TEST.ps1 to your Windows Desktop.
2. Open PowerShell in the Desktop folder.
3. Run: powershell -NoProfile -ExecutionPolicy Bypass -File .\JAAD-STAGING-AUTH-READ-TEST.ps1
4. Enter staging Supabase Project URL (Settings > API), staging PUBLISHABLE/anon key,
   the two staging account emails and staging passwords when prompted.
5. Never paste credentials, keys or tokens into chat. Share only the PASS/FAIL summary.
This test does not write or delete data. Do NOT use production credentials/URL.
